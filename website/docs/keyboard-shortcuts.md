# Keyboard shortcuts

## Navigation

```text
↑ / k       move up
↓ / j       move down
Enter       connect or open
Esc         back or close modal
q           quit or back
```

## Dashboard actions

```text
/           search
a           add host
e           edit host
d           delete host
s           open SSHDeck Files prototype
t           tunnel command generator
r           command runner prototype
h           health panel placeholder
l           logs
,           settings
Ctrl+p      command palette
?           help
```

## Files navigation target

SSHDeck Files is designed around Yazi-style movement:

```text
j / k       move
h / l       parent or open
Space       select
.           toggle hidden files
Tab         dual-pane view
T           transfers
:           command mode
```

Some Files operations are prototypes until transfer and remote mutation workflows are complete.
