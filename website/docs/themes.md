# Themes

SSHDeck includes three terminal themes:

- Blackout default
- Cyber
- Minimal

Themes control border style, foreground and background color, selected row style, warning and error colors, modal style, toast style, and active pane emphasis.

## Accessibility modes

Settings include:

```toml
[ui]
animations = true
unicode = true
nerd_font = true
```

Turn these off for older terminals, reduced motion needs, or non-Nerd-Font environments.

## Design direction

The default theme is intentionally black, calm, and practical. It avoids noisy gradients inside the TUI and uses subtle borders, status colors, and spacing for hierarchy.
